# Locally hosted typefaces

Downloaded from the Google Fonts source repository on 2026-10-24.
Both fonts use the SIL Open Font License 1.1; original license files are included.

- Inter variable (optical size / weight): https://github.com/google/fonts/tree/main/ofl/inter
  Product navigation, labels, forms, tables, findings and body content.
- DynaPuff variable (width / weight): https://github.com/google/fonts/tree/main/ofl/dynapuff
  Brand wordmarks and the Overview hero only. An original typographic treatment inspired by the supplied playful reference, not a copy of its artwork or an assertion of the reference font's identity.

Fonts are served by the app; no third-party font requests or tracking are required.
